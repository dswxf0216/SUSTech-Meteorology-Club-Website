# 配对小游戏

入口 `/game`。题库版本 `baitu-2026-v2`，五组22对，答案、云图和设备图来自活动题单。

服务器保存游戏状态并核对配对。实际用时按服务器开始及结束时间计算，每配错一次加5000毫秒；最终总用时为实际用时加惩罚用时，排行榜按总用时排序。旧成绩读取时按原实际用时和配错次数补算惩罚，保留记录。无昵称不保存排行榜；同用时按配错次数、完成时间排序。前50条公开展示，最多保留1000条成绩。昵称不是账号，不做身份唯一性验证，每次通关均可形成独立记录。

页面底部二维码指向 `https://nkweather.top/game`，本地图片无需第三方二维码服务。使用 Python 的 qrcode 库运行 `tests/generate-game-qr.py` 可重新生成。

数据目录为 `media/.matching-game/baitu-2026-v2/`。四组版本的成绩保留在原 v1 目录，不与五组成绩混排；旧会话需重新开始。生产部署已有 `/app/media` 持久化卷，更新应用不丢数据；备份媒体目录时一并备份此目录。只支持当前单实例、本地持久化卷部署；扩容前应迁移到共享数据库。不要把此目录复制到 `public` 或设置公开静态目录。游戏会话一小时失效，下一次开始时清理过期会话，排行榜保留。

使用独立会话锁、排行榜锁和原子文件替换防止并发写入覆盖；最后配对重复请求不会重复排名。游戏没有登录，无法保证昵称身份真实性，也不能完全阻止脚本答题，若用于正式兑奖需要额外核验。

本地验证：启动开发服务到3104后运行 `node tests/matching-game-smoke.mjs`。该测试会生成一个昵称成绩，务必只对本地环境运行。可用 `GAME_TEST_URL` 指定另一个本地测试地址。

云图采用题单原图、原答案，发布前建议组织者确认图片版权和云种标注，特别是层云、积雨云两题。
